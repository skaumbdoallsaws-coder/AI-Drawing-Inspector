# D12 / MI4 isolated model-import browser verifier

Date: 2026-11-09. Builder handoff; no commit, index/history changes, network
requests, server launch, browser launch, or package installation by this builder.
The concurrent MI2b/MI3b implementation files were not edited.

## CHANGED

- tools/verify_model_import_chat_browser.py: standalone CLI using the real
  server.py app in a background uvicorn thread and Playwright's sync API. A
  prebound free 127.0.0.1 socket stays reserved until uvicorn adopts it; ports
  8181, 8480, 8491 and 8493 are forbidden. The host provisions its real local
  site/layout through ensure_bootstrap.
- Environment is rebuilt before application imports. Dotenv is disabled both
  by PYTHON_DOTENV_DISABLED and a no-op load_dotenv. Desktop facility flags are
  applied from the actual feature flag tuples; design LAB/SAGE flags are off.
  Private assets and Codex edit previews are on, paid/subscription inference is
  off. Library, facility/import stores, catalog/generated assets, databases,
  documentation stores, application profiles/caches and TEMP/TMP are isolated.
  HF/Transformers are offline. Existing installed Chromium binaries are reused;
  no persistent browser profile or storage state is loaded.
- Constructor-only host paths are redirected before server imports. Relative
  generated paths use the temporary working directory. Static routes and index
  responses read the actual worktree files. Additional generated/runtime Path
  globals are relocated. Optional model/search lifespan initialization is off;
  the lazy /api/profiles inspector initializer is also disabled, retaining the
  real route's disk fallback against the empty temporary library.
- Python writes are guarded to the temporary/evidence roots; protected data
  reads, external connections/DNS, and connections to forbidden ports fail
  closed. Chromium external requests and service workers are blocked. A server
  request allowlist rejects chat/provider endpoints if browser interception is
  missed. Upload, poll and real worker responses are never mocked. Python
  children use CREATE_NO_WINDOW on Windows.
- UI navigation uses the real Drawing and Workflows tabs, the production
  trainingTypeRibbonSelect change event, _selectAgent('deviation-analyst') and
  the right chat rail. It checks a loaded saved binding and manualAuthoring,
  menu visibility, the hidden input, ordered uploading/checking/ready DOM
  states, pending send blocking, refusals, the send payload and successful chip
  clearing. Exact selectors/functions are printed and recorded in lookedFor.
- A fresh browser context repeats the same navigation without attachments to
  capture baseline console/page errors. Only matching error signatures are
  allowed in the attachment run; all baseline errors, new errors, blocked
  requests and route problems are listed in report.json. This is a no-attachment
  baseline on the current page, not a historical-commit comparison.
- Chat POSTs are fulfilled only in Playwright with a minimal successful real
  facility envelope, including READ_ONLY policy, empty tool_calls and
  registeredAssets, and ordered v1 SSE events when streaming. The captured
  payload must carry the real ready/refused import IDs and the bound layout.
- Screenshots include the nonfacility view, facility baseline, attachment menu,
  uploading/checking (at intercepted requests before continuing the real
  requests), terminal chips and before/after send. Timeouts also capture chip
  evidence. report.json records every check, including not-run checks after a
  fatal failure. Browser/context closure, server should_exit/join, host worker
  closure and temporary-store cleanup run in finally paths.
- tests/test_model_import_browser_harness.py: eight offline helper tests for
  route boundaries, allowed real paths, SSE/JSON completion, ordered chip
  transitions, file/network guards, environment/flags, forbidden port handling
  without binding a socket, and baseline-vs-new error reporting.
- docs/sage-model-import-reports/D12.md: this report.

Run in Claude's real environment, with its existing server dependencies and
Playwright Chromium installed:

    python tools/verify_model_import_chat_browser.py --glb <path> --out <dir>

Exit 0 requires every check to pass. Exit 1 keeps screenshots and report.json.
There is no fixed-port option, model fallback, dependency install, or download.

## DEVIATIONS

- The requested raw .obj -> refused behavior differs from committed MI4:
  newChip rejects unsupported extensions locally as failed, with a reason and
  no importId. The script deliberately records that as a failed check instead
  of changing the expectation or modifying the frontend. It then adds a third
  chip, an allowed ZIP containing only that OBJ, to exercise a real worker
  refusal. The subsequent send must include the GLB and refused ZIP IDs and
  exclude the failed raw OBJ. The successful send must clear all three chips.
  This fallback does not turn the raw-OBJ assertion green.
- Uvicorn's optional application lifespan and lazy inspector initialization
  are disabled to satisfy the no-model/no-network requirement. The actual
  facility host, routes, bootstrap, storage and import worker run unchanged;
  the host is explicitly closed after uvicorn stops.
- Helper tests were added because isolation and mock stream framing must be
  reviewable even where the full application cannot run.
