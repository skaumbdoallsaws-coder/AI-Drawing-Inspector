# Specification Sheet Workflow

InspectorPro specification sheets are one-page, evidence-bound product summaries
hosted by the shared Documentation workspace. The first profile targets MMLE-50D
and uses only reviewed claims from the Operations Manual evidence register.

The profile controls customer-facing labels and feature selection. The compiler
resolves values and provenance from the evidence register, binds a fresh assembled
CAD capture to the compiled document revision, and exports a one-page PDF. Values
that are missing, conflicted, or not approved for the profile are rejected rather
than inferred.

The reference TLIFT440 sheet is a presentation reference only. Its first and second
pages contain conflicting capacity and lift-height values, so none of its product
facts are used by InspectorPro.
