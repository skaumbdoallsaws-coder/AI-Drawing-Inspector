# Reason About Motion

Treat the motion package as precomputed kinematic evidence, not a live physics simulation.

## Procedure

1. Identify the requested semantic motion group by exact ID, label, function, or mapped part numbers.
2. Describe the motion relationship using package facts and current playback state.
3. Cite event angles, stroke, or other values only when present in the package summary.
4. Call RPM a visualization rate unless operating-speed evidence is separately provided.
5. For an FAI deviation, explain only how the affected interface participates in the nominal motion.

## Boundaries

- Do not invent forces, loads, velocity, acceleration, clearance, firing order, or operating RPM.
- Playback shows nominal geometry. It does not simulate looseness, collision, wear, or a failed dimension.
- Do not start, stop, or change motion for an explanation question.
- If no matching motion group exists, say that motion evidence is unavailable.
