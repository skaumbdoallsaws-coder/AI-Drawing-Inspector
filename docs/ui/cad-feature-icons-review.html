Design Rules Tested Here

Rendering: flat SVG faces, three-tone solids, one dark edge stroke, no per-icon plates, no runtime glow, no proprietary artwork.
Color grammar: blue means base geometry, amber means added/focus material, dark blue means cut or void, green means reference geometry, magenta means sketch/curve, RGB is reserved for axes.
Implementation: ship as inline SVG symbols or a project sprite; row state is CSS-only: selected row background, suppressed opacity/grayscale, and separate warning/error badges rather than baked-in icon states.
