# Area 10: Demo Readiness

## Schedule

- Start: August 16, 2026
- End: August 16, 2026
- Time: 1 day, 2 hours

## What This Area Must Address

This area prepares a working product demonstration that can begin immediately if requested. It is not a presentation. The goal is to show one compelling customer outcome quickly while remaining able to answer interruptions.

The work must address:

- The fastest path to the FAI and assembly-impact magic moment.
- What the interviewer should notice.
- Which parts of the workflow are automatic.
- What data was prepared in advance.
- How the workflow generalizes beyond the piston example.
- What to do if generation, rendering, networking, or the model call fails.
- How to switch to a backup without wasting interview time.

## Session Plan

- Prepare the app, sample data, viewport, and browser before the call.
- Reduce the live path to a 30-to-60-second outcome.
- Practice beginning at any step if interrupted.
- Prepare a short answer to whether the demo is hardcoded.
- Verify the backup video and one static evidence capture.
- Test audio, screen sharing, browser zoom, and notifications.
- Write a pre-interview readiness checklist.

## Deliverables

- Primary demo path.
- Backup demo path.
- Demo fact sheet identifying prepared and generated elements.
- Technical-failure response.
- Screen-sharing and environment checklist.

## Definition of Done

This area is complete when the working product is already loaded, the value appears within one minute, Shadrack can answer while operating it, and a failure can be handled honestly without derailing the conversation.
