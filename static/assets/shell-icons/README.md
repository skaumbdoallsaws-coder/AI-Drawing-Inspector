# InspectorPro Shell Icons v1

Original application-shell icon set.

Top toolbar: Home, New Document, Save, Print, Undo, Redo, Pointer, Notifications, Settings.
Left rail: Drawing, 3D Model.

Themeable SVGs use `--ip-icon-fg` and `--ip-icon-accent`.
Recommended visible sizes: 18–20 px toolbar, 24–28 px left rail.
