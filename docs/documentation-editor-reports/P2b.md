### Supervisor fixes (Claude)

The PDF layout now mirrors the canvas box (documentation_rich_text.js render() inside .documentation-object.text), where one page px is one PDF point:
- Lines are LINE_HEIGHT (1.2) x the size, with the CSS half-leading baseline.
- PADDING (3) sits inside the outline width (border-box), and the border stroke is drawn inside the box.

  - never before closing punctuation, small kana or iteration marks;
  - never after opening punctuation;
